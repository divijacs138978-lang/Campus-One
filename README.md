# Campus-One

CampusOne is a local-only student life and academic hub prototype built with React + Vite. It brings together academic planning, opportunity discovery, campus community interactions, analytics, and a study assistant demo in a single student portal experience.

## Features
- Overview dashboard with schedule, deadlines, announcements, and quick actions
- Academic Hub for subjects, assignments, timetable, examinations, and attendance
- Opportunity Explorer with searchable categories, filters, and tracking states
- Campus Community feed and study group management demo
- Academic Insights dashboard with computed metrics and study activity chart
- AI Study Assistant demo interface for study planning and concept help

## Local run
- Install dependencies: `npm install`
- Run the app: `npm run dev -- --host 0.0.0.0`
- Build for production: `npm run build`
- Lint: `npm run lint`

## Notes
- This project is designed as a local prototype and persists state in browser `localStorage`.
- No real backend, database, or live AI provider is connected yet.
